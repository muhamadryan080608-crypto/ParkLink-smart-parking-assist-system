# ParkLink-smart-parking-assist-system
PARKLINK is an IoT-based smart parking system using ultrasonic and infrared sensors, NFC authentication, automated gate control, LEDs, and an OLED display. It monitors parking availability and temperature while sending real-time status and alerts through Telegram.


# Parklink 

An ESP32-based smart parking system.

## Features

- Vehicle detection
- RFID access control
- Automatic gate
- OLED display
- Temperature monitoring
- LDR-based lighting
- Telegram notifications

## Hardware

- ESP32
- Ultrasonic sensors
- RFID reader
- Servo motor
- SSD1306 OLED
- LDR
- Temperature sensor
- Buzzer
- RGB LED

## Software

- Arduino IDE
- ESP32
- Arduino libraries
