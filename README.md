# ParkLink-smart-parking-assist-system
PARKLINK is an IoT-based smart parking system using ultrasonic and infrared sensors, NFC authentication, automated gate control, LEDs, and an OLED display. It monitors parking availability and temperature while sending real-time status and alerts through Telegram.


# Parklink Background

Parking management is an important challenge in modern urban areas, especially as the number of vehicles continues to increase. Conventional parking systems often require drivers to search manually for available spaces, resulting in wasted time, traffic congestion and unnecessary fuel consumption. In addition, manual parking management may provide limited access control and require continuous monitoring. Therefore, there is a need for a smarter and more efficient parking solution. Our PARKLINK is an IoT-based solution that integrates ultrasonic and infrared sensors, NFC authentication, a microcontroller and automated gate control. The system detects parking space availability and high temperature, verifies authorised users and controls vehicle access automatically. Parking status is indicated using LEDs, while parking availability and high-temperature alerts are communicated through the **Telegram App**, and the OLED display provides real-time system information. This project demonstrates how IoT technology can improve parking efficiency, security and management while supporting smarter and more sustainable communities.  

## Features

- Vehicle detection
- RFID access control
- Automatic gate
- OLED display
- Temperature monitoring
- LDR-based lighting
- Telegram notifications

- Fire alarm warning notification
